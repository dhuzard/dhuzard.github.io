Installing with Python¶

This page installs the udwa package into an isolated Python environment. If you’d rather not touch Python at all, use the Running with Docker (zero setup) route instead.

Tip

An isolated environment (a “virtual environment”, or venv) keeps this tool’s libraries separate from the rest of your system, so nothing else on your computer is affected. The steps below create one called .venv.

1. Check your Python¶

You need Python 3.10 or newer (3.12 is recommended). Check what you have:

py -3.12 --version

python3 --version

If you don’t have Python, download it from python.org (tick “Add Python to PATH” on Windows).

2. Create the environment and install¶

Run these from the repository’s top folder.

py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -U pip
.\.venv\Scripts\python.exe -m pip install -e ".[dev,ingest,report]"

python3 -m venv .venv
./.venv/bin/python -m pip install -U pip
./.venv/bin/python -m pip install -e ".[dev,ingest,report]"

That’s it — the core tool and the most useful optional features are installed.

3. Choosing what to install (optional extras)¶

The tool has a small, dependency-free core (everything needed to read a CSV and run the analyses) plus optional extras you switch on in the square brackets. Install only what you need.

Extra

What it adds

(none)

The core CSV path: ingest a CSV, run all circadian / spatial / behaviour / welfare / urine analyses, export results. Needs no extras.

ingest

Live DVC Analytics API ingestion — pull recordings straight from the DVC platform — plus an encrypted local store for your API key.

report

PDF report rendering.

formats

Read Parquet / HDF5 files in addition to CSV (for very large exports).

ai

The Circadiem AI circadian plot-scoring client (renders plots and scores them).

llm

Bring-your-own-key LLM narratives via the Anthropic API (opt-in; sends only summary tables — see AI insights & literature grounding).

dev

Developer tools: the pytest test suite and the ruff linter.

Combine extras with commas, e.g. install everything relevant to an analyst:

python -m pip install -e ".[ingest,report,formats,ai,llm]"

The core needs nothing extra

If you only want to load a CSV and run analyses, plain pip install -e . is enough. The optional imports are loaded lazily, so a missing extra only matters if you use that specific feature.

4. Check it worked¶

Two quick checks — start the app, and run the command line:

.\.venv\Scripts\streamlit.exe run app/streamlit_app.py
.\.venv\Scripts\udwa.exe tools

./.venv/bin/streamlit run app/streamlit_app.py
./.venv/bin/udwa tools

The first command opens the app at http://localhost:8501; the second prints the list of grounded analysis tools. Stop the app any time with Ctrl + C.

Next, head to the Quickstart: your first analysis to run your first analysis.

5. (Optional) Run the tests¶

If you installed the dev extra, you can confirm everything is healthy:

python -m pytest --basetemp=.pytmp

Note

The --basetemp=.pytmp flag avoids a Windows temp-folder permission quirk. A healthy run reports several hundred tests passing with a handful skipped (some tests need optional data or libraries that aren’t present in every environment).
