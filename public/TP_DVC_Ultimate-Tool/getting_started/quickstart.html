Quickstart: your first analysis¶

This walkthrough takes you from a running app to a full set of circadian, spatial and welfare results in a few minutes — using the bundled example dataset, so you don’t need any data of your own yet.

Before you start

Make sure the app is running (from Running with Docker (zero setup) or Installing with Python) and open at http://localhost:8501.

Step 1 — Load the example data¶

In the sidebar, click Import. Choose “Load bundled example” — this loads a real DVC cohort recording (Cohort7623) that ships with the tool.

Tip

When you’re ready to use your own data, this same screen lets you upload your DVC Metric CSV (and optional Event CSV), or pull recordings from the live DVC Analytics API. See Data input.

Step 2 — Run the preprocessing pipeline¶

Work down the sidebar steps — the app guides you through each one:

  1. Validate — confirm the detected subjects, groups and metrics look right.

  2. Metadata — (optional for the example) describe your study design.

  3. Events & Alignment — align recordings to an event (e.g. treatment day) and set exclusion rules for cage changes.

  4. Baseline, Aggregation & Pipeline — pick a time bin, then click Run full preprocessing pipeline.

This produces the clean, tidy “long-format” table that every analysis reads from.

Step 3 — Check data quality¶

Click Data Sanity. The tool runs an automatic traffic-light check (green / amber / red) for missing data, irregular sampling and other issues. This is your early-warning system — it’s worth a look before you trust any downstream numbers.

Step 4 — Run the core analyses¶

Click Core Analysis. You’ll get the established, descriptive metrics:

  • activity summary,

  • circadian rhythm (ZT) profile,

  • group means,

  • area-under-the-curve per animal,

  • the circadian cosinor fit (rhythm strength, peak timing, and a test that a rhythm exists).

Step 5 — Turn on the advanced analyses¶

Click Advanced Analysis to unlock the derived constructs and inference:

  • Sleep / rest — immobility-defined sleep and rest during the active phase,

  • Regularity (RDI) — how irregular the activity pattern is,

  • Welfare / anomaly — daily health score and flagged anomalies,

  • Spatial (EMF) — where in the cage the animals spend time,

  • UrinatoR — humidity-derived urine excretion,

  • Multivariate (PCA) — a whole-phenotype comparison across cages and days,

  • Group comparison statistics — estimation-first, exploratory contrasts.

Each analysis has an About panel citing the DVC paper that validates it. The science explains every one in detail.

Step 6 — See the chronobiology views and AI insights¶

Click AI Insights for:

  • the actogram, periodogram and activity onsets,

  • optional AI circadian scoring (Circadiem),

  • a plain-language narrative that turns the tables into readable, caveated prose. This is opt-in and sees only summary tables — never your raw data (see AI insights & literature grounding).

Step 7 — Export¶

Click Export to build a ZIP bundle containing your processed data, all analysis tables, the figures, a methods-ready reference list, and a provenance manifest (a SHA256 record of exactly what went in). Everything you need to reproduce — or publish — the result.

Prefer the command line?¶

The same analyses are available from a terminal. A minimal run:

# 1. Turn a DVC CSV into the tidy long format
udwa ingest --csv data/examples/Cohort7623_animal_loc__index_smoothed.csv -o long.csv

# 2. Run one analysis
udwa analyze -i long.csv --tool summarize_circadian_cosinor

See The command line for the full command reference.
