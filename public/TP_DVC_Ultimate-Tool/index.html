DVC Ultimate Tool¶

🐭 DVC Ultimate Tool¶

Turn Digital Ventilated Cage home-cage monitoring data into publishable, well-referenced behavioural science — without writing code.

Note

DVC = Digital Ventilated Cage (Tecniplast) — a home-cage activity sensor with 12 capacitive electrodes (e01–e12) under a standard individually ventilated cage. It is not Data Version Control.

The DVC Ultimate Tool (the udwa package — Ultimate DVC Workflow Agents) is a local-first analysis platform for continuous, 24/7 home-cage activity data. It ingests your DVC recordings, cleans and quality-checks them, and runs a battery of established circadian, spatial, behavioural, welfare and urine-excretion analyses — each one grounded in the peer-reviewed DVC literature. A point-and-click app means you never have to touch a terminal.

🚀 Get started

Install in a few minutes — or run it with zero setup via Docker — and load the bundled example dataset.

Reference & concepts

What can it measure?¶

🕑 Circadian rhythms

Cosinor with a rhythmicity test and confidence intervals, non-parametric IS / IV / RA, M10 / L5, actograms, and Lomb–Scargle periods for free-running designs.

🗺️ Spatial use

Per-electrode occupancy, spatial entropy, edge-vs-centre (thigmotaxis) ratio, and the Regularity Disruption Index (RDI).

😴 Behaviour & welfare

Sleep/wake estimation, rest-during-active-phase, rolling-baseline anomaly detection and a daily welfare/health score.

💧 Urine excretion

The UrinatoR pipeline: humidity-derived urine output for polyuria / diabetes screening, with a circadian (ZT) profile.

🤖 AI insights (opt-in)

A grounded narrative that turns the summary tables into plain-language, caveated prose — the model never sees your raw data.

📖 Literature grounding

Every analysis cites the DVC study that establishes it; an optional live search attaches supporting references.

The principles behind it¶

Four promises this tool keeps

  • Local-first / private. Your raw time series never leave your computer. Optional AI features see only small aggregated summary tables — never raw recordings.

  • Exploratory, never confirmatory. Estimation-first statistics (effect size

    • confidence interval + n before any p-value). No “significant” or “proven” claims.

  • Reproducible. Every run emits its configuration plus a SHA256 manifest, so a result can always be traced back to its inputs.

  • Well-referenced. Each analysis names the peer-reviewed DVC paper that validates it, so your methods section is defensible.
